# 04 DESIGN SYSTEM

## UI Architecture
- Dark mode by default (no light mode).
- Glassmorphism effects (`krish-glass` utility classes).
- Tailwind for styling.
- Framer Motion for micro-interactions and route transitions.

## Tokens
- Primary Accent: `#A855F7` (Purple).
- Background: `#06070B` (Deep Slate).

## Accessibility
- Must maintain ARIA roles on interactive elements.
- Ensure keyboard focus states are visible (even if custom).\n
