# 01 PROJECT VISION

Aura OS is an Agentic Enterprise Engineering System designed as a complete "digital OS" running in the browser.

## Existing Features
- Next.js 15 App Router architecture.
- Prisma ORM with PostgreSQL.
- NextAuth authentication.
- Core UI (Sidebar, Quick Access, Executive Planner).
- OS Modules (Goals OS, Study OS, Fusion OS).

## Planned Features
- Full predictive AI integration across all OS modules.
- Advanced Agent capabilities inside Fusion OS.
- Real-time global sync.

## Experimental Features
- Voice Chat integration.
- AI Vision file uploading.

## Deprecated
- Any previous plain React setups; strictly Next.js App Router.\n
